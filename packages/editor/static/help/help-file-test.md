# Pomoc

Przykładowy plik pomocy dla widgetu edytora. Pliki pomocy są w formacie Markdown i mogą zawierać nagłówki, listy, linki i inne elementy formatowania.

## Przykładowy nagłówek drugi poziom

### Przykładowy nagłówek trzeci poziom

Lista punktowana:

- Punkt 1
- Punkt 2

Lista numerowana:

1. Punkt 1
2. Punkt 2

Przykładowy `kod` w bloku kodu:

```
function example() {
    console.log("Hello, world!");
}
```

Przykład linku: [Kliknij tutaj](https://example.com)
