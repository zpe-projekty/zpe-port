# ZPE-Port

## Informacje ogólne

Biblioteka zpe-port udostępnia:

- interfejs do komunikacji między aplikacją a platformą ZPE.
- emulator platformy ZPE do testowania aplikacji lokalnie.
- edytor danych aplikacji dla nauczycieli.
- przykładowy projekt startowy aplikacji ZPE.

Więcej istotnych informacji znajdziesz na [wiki projektu](https://github.com/zpe-projekty/zpe-port/wiki).

## Chcę zobaczyć przykładowy projekt

Pobierz repozytorium

```bash
git clone https://github.com/zpe-projekty/zpe-port.git
```

Przejdź do katalogu z przykładowym projektem

```bash
cd zpe-port/example
```

Zainstaluj zależności

```bash
npm install
```

Uruchom aplikację w emulatorze

```bash
npm run dev
```

Otwórz w przeglądarce adres http://localhost:8080
